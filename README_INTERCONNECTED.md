Authoritative shared case model: **ONE PROJECT → ONE PARCEL → ONE LANDOWNER → SHARED DOCUMENTS + GIS EVIDENCE → CONNECTED OFFICERS → ONE CASE HISTORY**.

- P-001 / Survey 125 / 2.5 acres / Demo Owner A
- P-002 / Survey 126 / 3.0 acres / Demo Owner B
