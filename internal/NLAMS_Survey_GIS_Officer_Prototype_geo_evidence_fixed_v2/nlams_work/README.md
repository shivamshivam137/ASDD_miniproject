# NLAMS — Survey/GIS Officer Prototype

SIH Problem Statement 26016 — Real-Time National Land Acquisition & Management System.

## Run in VS Code

1. Extract the ZIP.
2. Open the extracted `nlams-survey-gis-officer` folder in VS Code.
3. Open the integrated terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite (normally `http://localhost:5173`).

## Demo

This is a frontend prototype with mock data. No backend or paid API is required.

Main demo flow:
Dashboard → GIS Map → Select Parcel → Field Survey → GPS → Measurement → Boundary → Evidence → Review → Submit to LAO.

The map uses OpenStreetMap tiles and React Leaflet. Internet access is needed for map tiles.
